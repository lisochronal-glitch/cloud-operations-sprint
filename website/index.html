FEATURED PROOF

This portfolio site is itself a working AWS cloud project

This site is hosted on private Amazon S3, delivered through CloudFront, deployed automatically through GitHub Actions, and connected to a serverless visitor counter backend using API Gateway, Lambda, DynamoDB, and CloudWatch.

Live Architecture

  • Static site: HTML/CSS/JavaScript stored in a private Amazon S3 bucket
  • CDN: CloudFront provides public HTTPS delivery and caching
  • Backend: API Gateway routes POST /visit requests to a Python Lambda function
  • Database: DynamoDB stores visitor records and global counter totals
  • Visible proof: The footer visitor counter is returned from DynamoDB through the live backend path
  • Automation: GitHub Actions deploys site updates and creates CloudFront invalidations

Implemented Stack

  1. Private S3 + CloudFront hosting
  2. GitHub Actions CI/CD deployment
  3. API Gateway HTTP API
  4. Python Lambda backend
  5. DynamoDB visitor counter
  6. Visible footer counter
