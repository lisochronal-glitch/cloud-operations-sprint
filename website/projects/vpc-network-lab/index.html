AWS Networking Project

Secure VPC Foundation

A small company is migrating a simple web application to AWS. Customers need to access the website from the internet, but the backend application and future database must not be directly reachable from the public internet.

This project designs and provisions a secure VPC foundation with a public web tier, a private backend tier, separated routing, controlled Security Group rules, and CloudFormation-based deployment.

SOLUTION

Public web tier, private backend tier

The VPC is split into a public subnet and a private subnet. The public subnet has a route to an Internet Gateway and is used for internet-facing web resources. The private subnet uses separate routing and is reserved for backend resources that should not receive direct public traffic.

Security Groups control which traffic is allowed into the web tier and between tiers. This creates a simple, expandable foundation for a future web application and database without exposing backend resources unnecessarily.

VERIFICATION

Proving the requirements were met

  • The public web tier can be reached from the internet.
  • The private backend tier cannot be reached directly from the internet.
  • Route tables match the intended public/private design.
  • Security Groups allow only the required traffic.
  • CloudFormation can recreate the environment consistently.

SECURITY / COST CONTROL

Limited exposure, temporary resources

Only the web tier is designed for public access. Backend resources remain private, and the lab environment is removed after verification.

  • No direct public access to backend resources.
  • No NAT Gateway in the initial design unless private outbound access becomes necessary.
  • Temporary EC2 test resources used only for verification.
  • CloudFormation stack deleted after screenshots and testing are complete.
