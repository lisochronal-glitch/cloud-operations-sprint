AWS Networking Project

Secure VPC Foundation

A small company wants to migrate a simple web application to AWS. Customers must be able to access the website from the internet, but the backend application and future database must not be directly reachable from the public internet.

This project designs a secure AWS network foundation that separates public web access from private backend resources.

Back to Projects GitHub coming soon

SOLUTION

Public web tier with private backend isolation

The Amazon VPC is split into a public subnet for the web tier and a private subnet for backend resources. The public subnet uses an Internet Gateway and public route table so customers can reach the website from the internet.

The private subnet has no direct public internet route, keeping backend resources isolated. Security Groups restrict inbound traffic and control communication between the public and private tiers. The infrastructure is provisioned with CloudFormation so the network can be recreated, tested, and removed cleanly.
